# 915MHz-RF-Filter
Compact 50 ohms RF filter designed for ISM-band applications and out-of-band interference rejection

## Key Specifications
Centre Frequency: 915MHz
Impedance: 50 ohms
Connector type: u.fl
Ultra compact PCB implementation

## Measured Performance
Measured using a calibrated VNA setup with SOLT calibration
